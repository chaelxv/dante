# 단테와 스텔라의 포근한 하루

단테(검은 고양이 귀·올리브색 눈·붉은 레이싱 수트)와 샴고양이 스텔라의 개인 생활 시뮬레이션 웹게임입니다.
모바일·Windows PC·Mac 웹브라우저에서 실행되는 **정적 웹사이트**입니다. 외부 라이브러리나 계정, 서버, 음원을 요구하지 않습니다.

## 포함된 기능

- **홈 화면:** 방에서 단테 이동, 가구 누르기, 말풍선, 하트 효과, 스텔라와 놀기
- **옷장:** 전신 의상 9종, 미리입어보기와 실제 착용 저장, 감정 반응 6종(모든 의상에서 감정 마크·반응 효과 적용; 모든 의상에 실제 눈·입이 변경되는 54개 얼굴 시트는 아님)
- **목욕:** 샴푸 거품 → 물로 헹구기 → 수건으로 닦기 → 로션 바르기, 4단계. 거품·물방울 애니메이션이 추가되었으며 기존보다 오래 직접 조작합니다. 터치·마우스 제스처와 버튼 모두 지원
- **수면:** 잠옷을 입고 **단테와 스텔라가 함께 이불을 덮고 자는** 일러스트. 이불 드래그 → 전등 끄기 → 다음 날 아침 복귀
- **요리:** 오므라이스·팬케이크·파스타·샌드위치·크림수프·오이무침 등 6종. 재료 선택 → 손질 → 섞기 → 가열/조립. 레시피별 화기 사용 구분
- **식사:** 의자에 앉은 단테와 전신 스텔라의 분리형 일러스트, 선택한 음식 이미지·실제 재고 반영, 3번 나눠 먹이기
- **상점:** 리본 토끼, 하트 쿠션, 캣타워, 털실공 등 9종. 구매한 가구는 홈에서 마우스나 손가락으로 끌어 위치 이동 후 저장
- **일기장·코인·스탯·일일 목표·백업/복원**

## 폴더 구조

GitHub 저장소에 압축을 풀어 **다음과 같이 저장소 바로 아래에** 업로드해 주세요.

```text
index.html
styles.css
game.js
sw.js
manifest.webmanifest
.nojekyll
icon-192.png
icon-512.png
assets/
  scenes/             # 방·욕실·수면 배경
  characters/outfits/ # 의상 9종
  characters/expressions/ # 표정 원본 이미지 6종
  characters/actions/     # 단테 추가 행동·식사·목욕·잠옷 파츠 17종
  stella/             # 샴고양이 기존 5포즈 + 새 전신·행동 10종
  food/               # 요리 6종
  shop/               # 상점 소품 9종
```

**ZIP 파일 자체를 업로드하면 웹사이트로 실행되지 않습니다.** 압축을 푼 내부 파일을 업로드해야 합니다.

## 새 GitHub Pages 웹사이트 만드는 방법

기존 `woojae` 저장소를 **덮어쓰지 마세요.** 반드시 새 저장소인 `dante`를 사용해 주세요.

1. GitHub에 로그인하고 <https://github.com/new>에서 새 저장소를 만듭니다.
2. **Repository name:** `dante` (현재 사용하시는 저장소 이름 기준). **Public**을 선택합니다. README 자동 생성은 선택하지 않으셔도 됩니다.
3. 새 저장소의 **Add file → Upload files**에서 이 ZIP의 압축을 푼 `index.html`, `styles.css`, `game.js`, `assets` 폴더 등 **전체**를 끌어 넣고 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`로 설정합니다.
5. Branch: `main`, Folder: `/ (root)`를 선택하고 **Save**합니다.
6. Actions의 **pages build and deployment**가 초록색 성공으로 바뀌면 새 주소에 접속합니다.

GitHub 계정이 `chaelxv`이고 저장소 이름이 `dante`라면 웹사이트 주소는 다음과 같습니다:

**https://chaelxv.github.io/dante/**

주소가 바로 안 열리면 배포 상태를 확인하고 새로고침해 주세요.

## 로컬에서 실행하기

폴더를 로컬 웹서버에서 열면 PWA와 이미지 경로까지 확인할 수 있습니다.

```bash
python3 -m http.server 8000
```

그 후 <http://localhost:8000>에 접속하면 됩니다. `index.html`을 더블클릭해도 기본 게임은 열릴 수 있지만 브라우저에 따라 저장/서비스 워커 관련 기능에 차이가 있으므로 웹서버를 권장합니다.

## 데이터 보관

게임은 브라우저별 `localStorage`에 자동 저장됩니다. **같은 게임 주소라도 다른 브라우저·기기와 저장 내용이 자동으로 동기화되지는 않습니다.**
게임 안의 **설정 → 백업 JSON 저장**으로 백업하고 다른 기기의 **백업 JSON 불러오기**로 복원할 수 있습니다.

사용하는 저장 키는 `dante_stella_cozy_v1`로, 우재 게임과 독립됩니다. 브라우저 데이터를 삭제하면 저장 내용이 사라질 수 있으므로 백업을 권장합니다.

## 제작 참고 및 한계

- 이 프로젝트는 개인 프로젝트 용도이며, 배경·기존 캐릭터·음식·상점 자산과 새 추가 동작 시트를 함께 제공합니다. 생성된 시트의 일부 원본은 프레임 경계에서 연결이 어색할 수 있으니 필요한 경우 추가 아트 보정이 가능합니다.
- 목욕/요리 등은 브라우저 터치 이벤트와 클릭으로 구현되어 있습니다. 정식 상용 게임 엔진의 물리 연출과는 다릅니다.
- Mac용 설치형 `.app`은 이 ZIP에 포함되지 않습니다. Mac에서 **웹사이트로 이용**하거나 지원하는 브라우저에서 앱처럼 홈 화면/독에 추가할 수 있습니다.
- `sw.js`는 HTTPS에서만 오프라인 캐시를 등록하며, 기존 업데이트가 바로 보이지 않으면 강력 새로고침이나 브라우저 캐시를 점검하세요.
